# Вторичные страницы: тексты и постановка визуала

Каноны: `docs/02-information-architecture.md`. Машинная копия: `data/secondary-content.json`. Абзацы ниже готовы для вёрстки. Источники и инструкции по визуалу служебные, не показывать их пользователю сайта.

Якорь секции равен id. Все дополнительные anchor_aliases нужно отрисовать как адресуемые элементы перед заголовком со scroll-margin-top. Ключевой смысл и ссылки видны без раскрытия.

Чередовать предметный split, текстовый блок, последовательность шагов и галерею по смыслу. Не делать одинаковые карточки для всех секций. Административные страницы компактны, без полноэкранных hero. Схемы не имитируют рабочий кабинет. Для prefers-reduced-motion все блоки видны сразу, анимации выключены.

### Работа терминала · `#stable-work`

Терминалы SkySend работают на базе операционной системы FastSYS, построенной на ядре Linux. ПО анализирует работу устройств, устраняет ошибки купюроприёмника, модема и фискального регистратора, поддерживает удалённые бинарные обновления.

Визуал `terminal-product`: Подлинное фото устройства из исходника, на нейтральном фоне. Название модели только по источнику. Без людей, 3D-реконструкции и декора.

Анимация: Содержимое доступно сразу в конечном состоянии. Все числа, easing, desktop/mobile и reduced-motion брать из data/motion-spec.json: contentAliases.none.

Источник: https://skysend.ru/partners/agent/stable-work.html.

## Решения по конфликтам

- Адрес по умолчанию: «Адрес офиса уточняйте по телефону». Главная указывает Монтажников 1/4, контакты Красных Партизан 218; индексы также расходятся.
- Публичная копия использует support@inf-sys.ru из контактов, @infsysgroup из поддержки и +78005552536 из шапки. /about/feedback.html содержит support@isg.dev; старые POS/шлюзовые статьи другой телефон. Альтернативы сохранены в аудите.
- Состав руководства не подтверждён на 2026. Доступны две биографии с атрибуцией источнику; три других URL имеют soft 404.
- Публикуется контакт отдела кадров. Старые должности не выдаются за открытые вакансии.
- Юридические сведения и банковские реквизиты сохранены в архиве; их актуальность не установлена. Не обновлять догадками.
- В новостях сохраняются юбилей 2024 и техническое уведомление 2022. Подключение терминалов 2024 и бизнес-миссия 2022 исключены как промо; в истории убраны автопробег, «Сладкие условия», рекламная платформа и проект «0%».
- В /exit.php?ml=1 обнаружены регистрационная ссылка https://cluster.skysend.ru:6716/#/ и POST action формы https://control.skysend.ru:6710. Регистрация дала ошибку TLS в среде аудита, кабинет ошибку DNS. GET кабинета не подтверждён; ссылки сопровождены работающим fallback поддержки. Пароли/формы не отправлялись, проверка сертификата не отключалась.
- Промо-части статей удалены: гарантии дохода, скидки, бесплатность, абсолютные обещания, неподтверждённые сроки. Функциональные механизмы сохранены с source URL. Противоречивые 1000/10000 транзакций в секунду в публичную копию не переносятся.
